# Описание проектов

## Проект 1: Крестики-Нолики

### Описание
Консольная реализация классической игры "Крестики-Нолики" для двух игроков. Игроки по очереди делают ходы на поле 3x3, пытаясь выстроить три своих символа в ряд по горизонтали, вертикали или диагонали.

### Особенности
- Ввод имен игроков
- Пошаговая игра с визуализацией поля
- Проверка победных комбинаций
- Определение победителя или ничьей
- Валидация вводимых позиций

### Технологии
- Java
- Консольный ввод/вывод
- Двумерные массивы

### Запуск
```bash
javac Main.java
java Main
```

# Змейка (Snake Game)

## Описание
Классическая аркадная игра "Змейка" с графическим интерфейсом на Java Swing. Игрок управляет змейкой, которая должна собирать еду, увеличиваясь в длину, при этом избегая столкновений со стенами и собственным телом.

## Особенности
- **Графический интерфейс**: Реализован на Swing с плавной анимацией
- **Управление**: Интуитивное управление стрелками клавиатуры
- **Система очков**: Подсчет текущего счета и рекорда (high score)
- **Визуальные эффекты**: 
  - Градиентное изменение цвета змейки (от ярко-зеленого к темно-зеленому)
  - Цветная еда (голубой цвет)
- **Игровой процесс**:
  - Генерация еды в случайных позициях
  - Постепенное увеличение длины змейки
  - Определение столкновений со стенами и собственным телом
- **Интерфейс**:
  - Экран начала игры с инструкцией
  - Экран завершения игры с результатами
  - Возможность перезапуска игры

## Технические детали
- **Размер поля**: 800x800 пикселей
- **Размер ячейки**: Автоматический расчет на основе размера поля
- **Частота обновления**: 20 FPS
- **Архитектура**: Объектно-ориентированный подход с разделением логики и отображения

## Технологии
- Java
- Swing (GUI framework)
- Graphics2D для отрисовки
- Обработка событий клавиатуры
- Таймер для игрового цикла
- Коллекции для управления состоянием игры
